# ADEVA Production House — Portal Gateway

A minimal, high-performance portal selection page designed for ADEVA Production House. It directs users to either the **Client Portal** or the **Studio Portal**.

![ADEVA Production House Preview](https://via.placeholder.com/1200x630.png?text=ADEVA+Production+House+Portal) *(Replace with a screenshot of your deployed site)*

## 🚀 Features

- **Dark Mode UI:** Designed with a sleek, modern dark palette matching the ADEVA brand aesthetic.
- **Fully Responsive:** Fluid layout that scales smoothly across desktop, tablet, and mobile devices.
- **Zero Build Tooling:** Built using vanilla HTML5, Tailwind CSS via CDN, and Lucide Icons—no compilation or dependencies required.
- **Accessible & Lightweight:** Fast load times with high contrast and clean markup.
